Complete this review **before** any authorization to start Docker, acquire dependencies, build or run. Record the
reviewer, the reviewed commit, the decision and any conditions. A builder self-check is not a review.

**Known residual risks to accept or reject explicitly:**
- The Docker Desktop VM is shared with the existing development containers.
- Docker-managed `/etc/hosts`, `/etc/hostname` and `/etc/resolv.conf` mounts are present in the worker.
- `linux/arm64` only.
- Reproducibility of the image ID is unproven until two builds match.
- P1 relies on a bitmap font, so its character error rate says nothing about real screenshots.
